# Bug list implementation plan

**Goal:** Show Backlog items classified as Bug in the Bug tab by default.

**Architecture:** Reuse BacklogPage with a fixed bug type, including pagination, existing issue details and shared query invalidation. Preserve the existing report and recognition views as secondary choices. This implements the user's confirmed design; no separate Bug data store is needed.

**Tech Stack:** React, Ant Design, React Query, Vitest.

## Constraints

- Fixed type must override URL filters and survive clearing filters.
- Quick creation in the Bug list creates Bugs.
- Existing Backlog behavior remains available without a fixed type.
- Preserve existing report access; require backlog permission before mounting its list.
